# Python

Use Python 3.10 or later and `requests`. Set the [shared environment variables](/examples#before-you-start) and put `report.pdf` in your working directory.

## Install the client

```bash
python -m venv .venv
. .venv/bin/activate
python -m pip install requests
```

## Upload a file

Save this as `upload.py`. The file size comes from the open file descriptor, and `requests` sends the file as a binary body.

```python [upload.py]
import os
from pathlib import Path

import requests

base_url = os.environ['FMS_URL'].rstrip('/')
filename = Path('report.pdf')

with requests.Session() as client:
    client.headers['Authorization'] = f"Bearer {os.environ['FMS_API_KEY']}"
    with filename.open('rb') as content:
        created = client.post(
            f'{base_url}/api/v1/uploads',
            json={
                'storageBackendId': os.environ['BACKEND_ID'],
                'originalFilename': filename.name,
                'declaredSizeBytes': os.fstat(content.fileno()).st_size,
                'mode': 'proxy_single',
            },
            timeout=30,
        )
        created.raise_for_status()
        file_id = created.json()['fileId']
        uploaded = client.put(
            f'{base_url}/api/v1/uploads/{file_id}/content',
            headers={'Content-Type': 'application/octet-stream'},
            data=content,
            timeout=120,
        )
        uploaded.raise_for_status()
        print(uploaded.json())
```

```bash
python upload.py
```

Save the returned `fileId`. Scanning runs asynchronously.

## Check and download

Save this as `download.py`. Run it with the file ID after scanning. It exits without downloading if the status is not `clean`.

```python [download.py]
import os
import sys
from urllib.parse import quote

import requests

base_url = os.environ['FMS_URL'].rstrip('/')
if len(sys.argv) != 2:
    raise SystemExit('Usage: python download.py <file-id>')
file_id = quote(sys.argv[1], safe='')
url = f'{base_url}/api/v1/files/{file_id}'

with requests.Session() as client:
    client.headers['Authorization'] = f"Bearer {os.environ['FMS_API_KEY']}"
    metadata = client.get(url, timeout=30)
    metadata.raise_for_status()
    status = metadata.json()['status']
    if status != 'clean':
        raise SystemExit(f'File is not clean: {status}')

    with client.get(f'{url}/content', stream=True, timeout=120) as content:
        content.raise_for_status()
        with open('downloaded-report.pdf', 'wb') as destination:
            for chunk in content.iter_content(chunk_size=65536):
                destination.write(chunk)
```

```bash
python download.py '<file-id>'
```
