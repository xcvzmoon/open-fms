# Nitro

This example uses standalone Nitro v3 on Node.js 26 or later. `POST /upload-report` uploads a server-side `report.pdf` using the [Node.js upload helper](/examples/nodejs#create-the-upload-helper).

## Add the route

In an existing Nitro v3 project, save the helper as `server/utils/fms.ts`. Install the helper's `valibot` dependency. Set the [shared environment variables](/examples#before-you-start) in the server process and put `report.pdf` in the project working directory.

```ts [server/routes/upload-report.post.ts]
import { defineHandler } from 'nitro';
import { uploadFile } from '../utils/fms.ts';

export default defineHandler(async () => {
  const uploaded = await uploadFile('report.pdf');
  return Response.json(uploaded, { status: 202 });
});
```

## Try it

Start Nitro on port 3001 so it can reach Open FMS on port 3000. With a project that uses Vite+:

```bash
PORT=3001 vp run dev
```

In another terminal:

```bash
curl --fail-with-body -X POST http://localhost:3001/upload-report
```

The response contains `fileId` and the current scan status. Use the [status and download requests](/examples/curl#check-scan-status) after uploading.

Add your application's authentication and authorization before exposing the route. This example reads a small local file into memory and requires a Node.js deployment with filesystem access.
