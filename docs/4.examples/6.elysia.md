# Elysia

This example runs Elysia on Bun. `POST /upload-report` uploads a server-side `report.pdf` using the [upload helper](/examples/nodejs#create-the-upload-helper), which also works with Bun's Node.js compatibility APIs.

## Set up

In an Elysia project, save `fms.ts` next to `server.ts`, add `report.pdf` to the working directory, and set the [shared environment variables](/examples#before-you-start).

Install `elysia` and the helper's `valibot` dependency with your package manager.

```ts [server.ts]
import { Elysia } from 'elysia';
import { uploadFile } from './fms.ts';

new Elysia()
  .post('/upload-report', async ({ set }) => {
    const uploaded = await uploadFile('report.pdf');
    set.status = 202;
    return uploaded;
  })
  .listen({ port: 3001, hostname: '127.0.0.1' });
```

## Run

```bash
bun server.ts
```

In another terminal:

```bash
curl --fail-with-body -X POST http://localhost:3001/upload-report
```

The response contains `fileId` and the current scan status. Use the [status and download requests](/examples/curl#check-scan-status) after uploading.

Add your application's authentication and authorization before exposing this route. The example reads a fixed small file from the server, rather than accepting a filesystem path from the request.
