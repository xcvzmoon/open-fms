# Express

This local Express 5 example uploads a server-side `report.pdf` when you call `POST /upload-report`. It uses the [Node.js upload helper](/examples/nodejs#create-the-upload-helper).

## Set up

Use Node.js 26 or later. In an Express project, save `fms.ts` next to `server.ts`, add `report.pdf` to the working directory, and set the [shared environment variables](/examples#before-you-start).

Install `express@5` and the development dependency `@types/express` with your package manager. Use an ESM project (`"type": "module"` in `package.json`) and install the helper's dependencies from the Node.js example.

```ts [server.ts]
import express from 'express';
import { uploadFile } from './fms.ts';

const app = express();

app.post('/upload-report', async (_request, response) => {
  const uploaded = await uploadFile('report.pdf');
  response.status(202).json(uploaded);
});

app.listen(3001, '127.0.0.1');
```

Express 5 forwards rejected async handlers to its error handler.

## Run

```bash
node server.ts
```

In another terminal:

```bash
curl --fail-with-body -X POST http://localhost:3001/upload-report
```

The response contains `fileId` and the current scan status. Use the [status and download requests](/examples/curl#check-scan-status) once the upload is accepted.

Before exposing this route publicly, add your application's authentication and authorization. The example uses a fixed server-side file; it does not accept client-supplied filesystem paths.
