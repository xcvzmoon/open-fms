# Examples

Practical snippets for common Open FMS flows.

## Create and finish a single upload

```bash
FILE_ID=$(curl -s -X POST "$FMS_URL/api/v1/uploads" \
  -H "Authorization: Bearer $FMS_API_KEY" \
  -H "Content-Type: application/json" \
  -d "{\"storageBackendId\":\"$BACKEND_ID\",\"originalFilename\":\"report.pdf\",\"declaredSizeBytes\":1024}" \
  | jq -r '.fileId')

curl -X PUT "$FMS_URL/api/v1/uploads/$FILE_ID/content" \
  -H "Authorization: Bearer $FMS_API_KEY" \
  --data-binary @report.pdf
```

## Download a clean file

```bash
curl "$FMS_URL/api/v1/files/$FILE_ID/content" \
  -H "Authorization: Bearer $FMS_API_KEY" \
  -o report.pdf
```

## Range request

```bash
curl -H "Range: bytes=0-1023" \
  -H "Authorization: Bearer $FMS_API_KEY" \
  "$FMS_URL/api/v1/files/$FILE_ID/content" \
  -o head.bin
```

## Redeem a setup code

```bash
curl -X POST "$FMS_URL/api/v1/signup/redeem" \
  -H "Content-Type: application/json" \
  -d '{"code":"<setup-code>"}'
```

## Health

```bash
curl "$FMS_URL/healthz"
curl "$FMS_URL/readyz"
```
