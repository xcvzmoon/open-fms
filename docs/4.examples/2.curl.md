# cURL

Use cURL and `jq` with the [shared environment variables](/examples#before-you-start). Run these commands from the directory containing `report.pdf`.

## Upload a file

Calculate the size from the file you will send. The upload API requires `mode` and `declaredSizeBytes`.

```bash
set -eu
SIZE=$(wc -c < report.pdf | tr -d ' ')
PAYLOAD=$(jq -n --arg backend "$BACKEND_ID" --argjson size "$SIZE" \
  '{storageBackendId: $backend, originalFilename: "report.pdf", declaredSizeBytes: $size, mode: "proxy_single"}')

FILE_ID=$(curl --fail-with-body -sS "$FMS_URL/api/v1/uploads" \
  -H "Authorization: Bearer $FMS_API_KEY" \
  -H 'Content-Type: application/json' \
  --data "$PAYLOAD" | jq -er '.fileId')

curl --fail-with-body -sS -X PUT "$FMS_URL/api/v1/uploads/$FILE_ID/content" \
  -H "Authorization: Bearer $FMS_API_KEY" \
  -H 'Content-Type: application/octet-stream' \
  --data-binary @report.pdf
```

## Check scan status

```bash
curl --fail-with-body -sS "$FMS_URL/api/v1/files/$FILE_ID" \
  -H "Authorization: Bearer $FMS_API_KEY" | jq
```

Repeat the status request until `status` is `clean`. Stop if scanning fails or rejects the file.

## Download a clean file

```bash
curl --fail -sS "$FMS_URL/api/v1/files/$FILE_ID/content" \
  -H "Authorization: Bearer $FMS_API_KEY" \
  -o downloaded-report.pdf
```

Request part of the file with a Range header:

```bash
curl --fail -sS "$FMS_URL/api/v1/files/$FILE_ID/content" \
  -H "Authorization: Bearer $FMS_API_KEY" \
  -H 'Range: bytes=0-1023' \
  -o head.bin
```

## Redeem a setup code

```bash
curl --fail-with-body -sS "$FMS_URL/api/v1/signup/redeem" \
  -H 'Content-Type: application/json' \
  --data '{"code":"<setup-code>"}'
```

## Check service health

```bash
curl --fail -sS "$FMS_URL/healthz"
curl --fail -sS "$FMS_URL/readyz"
```
