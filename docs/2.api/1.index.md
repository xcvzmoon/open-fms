# API

HTTP surface for Open FMS.

## Health

### `GET /healthz`

Process liveness only.

```json
{ "status": "ok", "uptimeSeconds": 42 }
```

### `GET /readyz`

Dependency readiness. PostgreSQL is reported separately.

```json
{
  "status": "ready",
  "checks": {
    "process": { "status": "ok" },
    "postgres": { "status": "ok" }
  }
}
```

## Auth

Better Auth mounts at `/api/auth/*`.

Service callers use API keys. Admin users use email and password.

## Uploads

### `POST /api/v1/uploads`

Create a file and upload session with exact `declaredSizeBytes` and `mode` (`proxy_single` or `proxy_parts`). Atomically reserves that byte count.

### `PUT /api/v1/uploads/{id}/content`

Stream a single object body. SHA-256 is computed in flight. Exact-size completion automatically seals the object and enqueues scanning. Writes after sealing are rejected.

### `PUT /api/v1/uploads/{id}/parts/{n}`

Upload one part.

### `POST /api/v1/uploads/{id}/complete`

Finalize a multipart upload. The server validates parts and hashes the stored bytes; client checksums and ETags do not establish integrity.

### `POST /api/v1/uploads/{id}/abort`

Abort and release reserved quota.

## Files

### `GET /api/v1/files/{id}`

Metadata for the owning caller.

### `GET /api/v1/files/{id}/content`

Proxy download. Supports `Range`. Only `clean` files.

## Registration and admin

| Endpoint                                        | Purpose                        |
| ----------------------------------------------- | ------------------------------ |
| `POST /api/v1/signup`                           | Verified-session caller signup |
| `POST /api/v1/signup/redeem`                    | Redeem setup code              |
| `POST /api/v1/admin/approvals`                  | Approve or reject caller       |
| `GET/PATCH /api/v1/admin/settings/signup`       | Signup settings                |
| `POST /api/v1/callers/{id}/keys`                | Issue key once                 |
| `POST /api/v1/callers/{id}/keys/{keyId}/rotate` | Rotate secret                  |
| `DELETE /api/v1/callers/{id}/keys/{keyId}`      | Revoke key                     |
