# API overview

Open FMS exposes HTTP routes under `/api`. Auth lives at `/api/auth`.

## Health

| Method | Path       | Description          |
| ------ | ---------- | -------------------- |
| GET    | `/healthz` | Process liveness     |
| GET    | `/readyz`  | PostgreSQL readiness |

## Auth and signup

| Method | Path                    | Description                       |
| ------ | ----------------------- | --------------------------------- |
| *      | `/api/auth/*`           | Better Auth endpoints             |
| POST   | `/api/v1/signup`        | Self-signup (allowlisted domains) |
| POST   | `/api/v1/signup/redeem` | Redeem setup code                 |

## Uploads

| Method | Path                             | Description             |
| ------ | -------------------------------- | ----------------------- |
| POST   | `/api/v1/uploads`                | Create upload session   |
| PUT    | `/api/v1/uploads/{id}/content`   | Proxy single upload     |
| PUT    | `/api/v1/uploads/{id}/parts/{n}` | Upload one part         |
| POST   | `/api/v1/uploads/{id}/complete`  | Finalize upload         |
| POST   | `/api/v1/uploads/{id}/abort`     | Abort and release quota |
| GET    | `/api/v1/uploads/{id}`           | Upload status           |
| POST   | `/api/v1/uploads/{id}/grants`    | Mint upload pass        |

## Files

| Method | Path                         | Description                 |
| ------ | ---------------------------- | --------------------------- |
| GET    | `/api/v1/files/{id}`         | File metadata               |
| GET    | `/api/v1/files/{id}/content` | Download bytes (clean only) |

## Credentials and admin

| Method    | Path                                       | Description               |
| --------- | ------------------------------------------ | ------------------------- |
| POST      | `/api/v1/callers/{id}/keys/{keyId}/rotate` | Rotate API key secret     |
| DELETE    | `/api/v1/callers/{id}/keys/{keyId}`        | Revoke API key            |
| POST      | `/api/v1/admin/approvals`                  | Approve or reject callers |
| GET/PATCH | `/api/v1/admin/settings/signup`            | Signup settings           |

## OpenAPI

In development:

- Spec: `/_openapi.json`
- Scalar UI: `/_scalar`

## Status codes

| Code | Typical meaning                             |
| ---- | ------------------------------------------- |
| 401  | Authentication required                     |
| 403  | Capability missing or file not downloadable |
| 404  | File or caller not found                    |
| 409  | Lifecycle conflict (`row_version`)          |
| 413  | Quota exceeded                              |
| 503  | Not ready (`/readyz`)                       |
