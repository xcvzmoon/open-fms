# Security

## The download rule

Only files with PostgreSQL status `clean` may be streamed.

This is a hard rule. Signed URLs cannot be revoked after a file leaves `clean`, so v1 proxies every download and re-checks state per request.

## Auth

- Better Auth handles sessions, passwords, API keys, and rate limits
- `caller_credentials` stores FMS policy: scopes, CIDR, size, rotation
- Setup codes and upload passes are HMAC hashes with a versioned pepper

## Isolation

Each request has one `caller_id`. Queries filter by tenant. Admin routes are the only cross-tenant paths.

## Not in v1

- Presigned GET downloads
- Automatic status repair from reconcile
- Enabling storage backends before compatibility tests
