# Quick start

Get a local Open FMS stack running in a few commands.

## Requirements

- Node.js 26
- pnpm 12.5.1 (via Vite+)
- PostgreSQL 16
- Optional object storage and SMTP

## Install

```bash
git clone https://github.com/xcvzmoon/open-fms.git
cd open-fms
cp .env.example .env
vp install
```

## Configure

```bash
DB_URL=postgres://user:pass@localhost:5432/open-fms
BETTER_AUTH_SECRET=replace-with-openssl-rand-base64-32
BETTER_AUTH_URL=http://localhost:3000
AUTH_TOKEN_PEPPER=replace-with-openssl-rand-base64-32
MAIL_MODE=mock
```

## Migrate

```bash
vp run --filter "@open-fms/database" migrate
```

Migrations are operator or CI steps. The API never migrates on boot.

## Run

```bash
npm run dev --prefix apps/api
```

Production build:

```bash
npm run build --prefix apps/api
```

## Verify

```bash
curl http://localhost:3000/healthz
curl http://localhost:3000/readyz
```

## Develop docs

```bash
cd docs
pnpm install
pnpm run dev
```

Continue with [configuration](/docs/configuration).
