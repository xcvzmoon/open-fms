# Configuration

## Environment

| Variable                      | Required | Purpose              |
| ----------------------------- | -------- | -------------------- |
| `DB_URL`                      | yes      | PostgreSQL DSN       |
| `BETTER_AUTH_SECRET`          | yes      | 32+ char auth secret |
| `BETTER_AUTH_URL`             | yes      | Public base URL      |
| `AUTH_TOKEN_PEPPER`           | yes      | Token HMAC pepper    |
| `AUTH_TOKEN_PEPPER_VERSION`   | no       | Default `1`          |
| `STORAGE_ACCESS_KEY_ID`       | for S3   | Storage access key   |
| `STORAGE_SECRET_ACCESS_KEY`   | for S3   | Storage secret       |
| `MAIL_MODE`                   | no       | `mock` or `smtp`     |
| `MAIL_FROM`                   | no       | From address         |
| `SMTP_HOST` / `SMTP_PORT`     | for smtp | SMTP endpoint        |
| `OTEL_ENABLED`                | no       | Enable tracing       |
| `OTEL_EXPORTER_OTLP_ENDPOINT` | no       | OTLP collector       |

## Scripts

```bash
vp run check
vp run typecheck
vp run test
vp run build
```

## Migrations

```bash
vp run --filter "@open-fms/database" generate
vp run --filter "@open-fms/database" migrate
```

## Scheduled tasks

| Task                   | Schedule  | Purpose                        |
| ---------------------- | --------- | ------------------------------ |
| `sweep-expired`        | every 15m | Expire codes, passes, sessions |
| `sweep-purge`          | hourly    | Purge files past `purge_after` |
| `sweep-reconcile`      | daily     | Report DB vs storage drift     |
| `observability-canary` | every 5m  | Process and storage health     |
