# Install and run

## Clone and install

```bash
git clone https://github.com/xcvzmoon/open-fms.git
cd open-fms
cp .env.example .env
vp install
```

## Configure

Set `DB_URL` and auth secrets first. Storage and mail settings can be added when those paths are used.

```bash
# PostgreSQL
DB_URL=postgres://user:pass@localhost:5432/open-fms

# Auth
BETTER_AUTH_SECRET=replace-with-openssl-rand-base64-32
BETTER_AUTH_URL=http://localhost:3000
AUTH_TOKEN_PEPPER=replace-with-openssl-rand-base64-32
AUTH_TOKEN_PEPPER_VERSION=1

# Mail
MAIL_MODE=mock
MAIL_FROM=Open FMS <hello@open-fms.example>
```

## Database migrations

Apply schema before tests or runtime:

```bash
vp run --filter "@open-fms/database" migrate
```

Generate new migrations when tables change:

```bash
vp run --filter "@open-fms/database" generate
```

## Run the API

```bash
npm run dev --prefix apps/api
```

Production build:

```bash
npm run build --prefix apps/api
```

## Health endpoints

- `GET /healthz` returns 200 when the process is up
- `GET /readyz` reports PostgreSQL readiness with separate checks
